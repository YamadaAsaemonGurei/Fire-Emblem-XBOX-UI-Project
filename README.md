# Fire Emblem Xbox Button Prompts

Xbox-style controller prompts for Fire Emblem: Three Houses and Fire Emblem: Fortune’s Weave. With the intended controller mapping, B confirms and A cancels. Each patch builds the mod from your own compatible RomFS dump.

| Game | Setup guide | Tested on |
| --- | --- | --- |
| Fire Emblem: Three Houses | [Three Houses instructions](three-houses/README.md) | The original prompt changes were confirmed in Lichii on v1.2.0. The v2 inventory-tab changes passed file and texture checks. |
| Fire Emblem: Fortune’s Weave | [Fortune’s Weave instructions](fortunes-weave/README.md) | Confirmed in-game in Lichii with the extracted build used to make the patch. |

Choose the ZIP for your game from **Releases** and follow the included README. Each game has its own build instructions and compatibility notes.

Codex assisted with texture and font editing, the patching scripts, and documentation. The individual guides explain the artwork and list the format references used.
